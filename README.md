# EDURA Frontend — Next.js & Redux LMS

This repository contains the Next.js 14 frontend application for the EDURA Learning Management System.

## Stack

- Next.js 14 App Router
- Redux Toolkit (State Management)
- Vanilla CSS for styling
- React Icons

## Getting Started

### Installation

```bash
npm install
```

### Run Locally

```bash
npm run dev
```

## Linting & Formatting

To run ESLint:

```bash
npm run lint
```
